# HUB73P481_ESP32 на ESP32-WROOM-32

Экспериментальный драйвер для классического ESP32 и панели DH-P4.81 52×52 с HUB73 и ICND2153S. В Arduino IDE выберите **ESP32 Dev Module** из пакета **esp32 by Espressif Systems**. Используйте версию пакета **3.3.5**. Установите Adafruit GFX Library и Adafruit BusIO. Добавьте ZIP библиотеки через меню **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку**.

[Скачать ZIP для Arduino IDE](https://github.com/raptirius-cyber/HUB73P481_ESP32/blob/main/HUB73P481_ESP32-1.0.1.zip).

## Подключение одной панели

| Сигнал HUB73 IN | GPIO ESP32 |
|---|---|
| R1 / G1 / B1 | 4 / 13 / 14 |
| R2 / G2 / B2 | 16 / 17 / 18 |
| R3 / G3 / B3 | 19 / 21 / 22 |
| R4 / G4 / B4 | 23 / 25 / 26 |
| A / B / C | 32 / 33 / 2 |
| LAT (LE) | 27 |
| OE (ROW) | 15 |
| CLK (DCLK) | 5 |
| GND | GND |

Подавайте 5 В от отдельного источника на силовой разъём панели. Объедините землю ESP32 и источника. Для согласования логических уровней можно использовать 74AHCT245 с питанием 5 В. GPIO 2, 5 и 15 участвуют в выборе режима при сбросе. Если панель или преобразователь уровней удерживает эти линии, отключите сигнальный шлейф на время загрузки прошивки и подключите его при выключенном питании.

## Первый запуск

Откройте **Файл → Примеры → HUB73P481_ESP32 → WroomBringUp**, загрузите скетч и откройте монитор порта на 115200. После `show OK` на экране ожидаются белая рамка, красный, зелёный и синий квадраты, надпись HUB73 и жёлтая диагональ. Изображение должно оставаться на экране. Сообщение содержит длительность `show()` для этого изображения, включая подготовку данных и ожидание DMA.

При наличии логического анализатора проверьте CLK около 8 МГц, включая паузы между вызовами `show()`, адреса 0–6 и обычный импульс ROW длительностью четыре такта CLK. На границе кадра команда VSYNC занимает три такта LE. Затем проверьте исходные примеры **Brightness** и **PanelLayout**.

I2S0 зарезервирован библиотекой. Вызывайте API из одной задачи. На ESP32 каждый такт хранится как 32-битное слово для DMA. Под кадр, кольца развёртки и RGB565 для одной панели нужно около 91 КБ. Для четырёх требуется около 279 КБ с учётом дескрипторов, поэтому на WROOM-32 выделение памяти может завершиться ошибкой. Начните с одной панели и наращивайте каскад после проверки на устройстве.

Электрические тайминги, изображение, яркость и каскад на реальном ESP32-WROOM-32 пока не проверялись.

## Использование в скетче

Подключите `#include <HUB73P481_ESP32.h>` и объявите `HUB73P481_ESP32 matrix;`. Для составного экрана доступны те же параметры столбцов, рядов и `ChainOrder`.
